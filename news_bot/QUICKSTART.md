# Быстрый старт Telegram News Bot

## 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2. Настройка (ОБЯЗАТЕЛЬНО!)

### Откройте файл `config.py` и заполните:

#### A. Telegram Bot Token
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен в `TELEGRAM_BOT_TOKEN`

#### B. Ваш Telegram User ID
1. Отправьте сообщение боту @userinfobot
2. Скопируйте числовой ID в `TELEGRAM_USER_ID`

#### C. Telegram API (для чтения каналов)
1. Перейдите на https://my.telegram.org/apps
2. Войдите под своим аккаунтом
3. Создайте новое приложение
4. Скопируйте `API ID` в `TG_API_ID`
5. Скопируйте `API Hash` в `TG_API_HASH`

#### D. AI API Keys (рекомендуется OpenAI)

**Вариант 1: OpenAI (лучшее качество)**
- Зарегистрируйтесь: https://platform.openai.com
- Создайте API ключ: https://platform.openai.com/api-keys
- Вставьте ключ в `OPENAI_API_KEY`
- Преимущества: GPT-4o для рерайтинга + DALL-E 3 для изображений

**Вариант 2: Text.ru (только текст)**
- Зарегистрируйтесь: https://text.ru/apikey
- Получите API ключ
- Вставьте ключ в `TEXT_RU_API_KEY`
- Для изображений понадобится отдельный сервис

## 3. Запуск

### Windows
```bash
start_bot.bat
```
Или вручную:
```bash
python bot.py
```

### Linux/Mac
```bash
python3 bot.py
```

### В фоновом режиме (Linux)
```bash
nohup python3 bot.py > bot.log 2>&1 &
```

## 4. Первое использование

1. Запустите бота
2. В Telegram отправьте боту `/start`
3. Для ручного сбора новостей: `/collect`
4. Бот пришлет список новостей с кнопками
5. Выберите интересные новости кликом по номерам
6. Нажмите "🚀 Обработать выбранные"
7. Получите рерайтнутый текст + изображение

## 5. Настройка расписания

В `config.py` измените:

```python
# Каждый будний день в 10:00
SCHEDULE_DAY_OF_WEEK = "mon,tue,wed,thu,fri"
SCHEDULE_HOUR = 10
SCHEDULE_MINUTE = 0

# Каждый день в 9:30
SCHEDULE_DAY_OF_WEEK = "mon,tue,wed,thu,fri,sat,sun"
SCHEDULE_HOUR = 9
SCHEDULE_MINUTE = 30
```

Допустимые дни: `mon, tue, wed, thu, fri, sat, sun`

## 6. Команды бота

- `/start` - Запустить бота
- `/collect` - Собрать новости вручную
- `/status` - Показать статус
- `/help` - Помощь
- `/process` - Обработать выбранные новости

## 7. Проверка работы

После запуска проверьте:

1. ✓ Бот отвечает на `/start`
2. ✓ Логи пишутся в `logs/bot.log`
3. ✓ При команде `/collect` приходит список новостей
4. ✓ Кнопки выбора работают
5. ✓ После обработки приходит рерайтнутый текст
6. ✓ Изображения генерируются (если настроен API)

## 8. Troubleshooting

### Ошибка "No module named 'telethon'"
```bash
pip install -r requirements.txt
```

### Бот не собирает новости с сайтов
- Проверьте доступность сайтов в браузере
- Некоторые сайты могут блокировать парсинг
- Смотрите детали в `logs/bot.log`

### Не читаются Telegram-каналы
- Убедитесь, что указали `TG_API_ID` и `TG_API_HASH`
- Проверьте, что каналы публичные
- Или добавьте бота в каналы как участника

### Ошибки AI обработки
- Проверьте баланс API ключа
- Убедитесь, что ключ активен
- Для OpenAI: https://platform.openai.com/usage

### Бот падает при запуске
- Проверьте правильность всех API ключей в `config.py`
- Убедитесь, что `TELEGRAM_USER_ID` - число (без кавычек)
- Смотрите ошибку в консоли или логах

## 9. Дополнительные настройки

### Изменение количества новостей
В `config.py` в секции `NEWS_SOURCES` измените `count` для каждого источника.

### Добавление новых источников
Добавьте новый источник в `NEWS_SOURCES` по аналогии с существующими.

### Смена модели AI
В `ai_processor.py` измените `self.model = "gpt-4o-mini"` на другую модель OpenAI.
