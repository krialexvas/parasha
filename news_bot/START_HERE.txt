================================================================================
    БЫСТРЫЙ СТАРТ - ЗАПУСК БОТА СБОРА НОВОСТЕЙ
================================================================================

ШАГ 1: Установите Python с сайта python.org (галочка "Add to PATH" обязательна!)

ШАГ 2: Откройте эту папку в командной строке и выполните:
       pip install -r requirements.txt

ШАГ 3: Скопируйте файл .env.example и переименуйте в .env
       Заполните его своими ключами (см. README.md)

ШАГ 4: Один раз выполните для настройки источников:
       python init_sources.py

ШАГ 5: Запустите бота:
       python main.py

       НЕ ЗАКРЫВАЙТЕ ОКНО! Бот работает пока окно открыто.

ШАГ 6: Напишите своему боту в Telegram /start
