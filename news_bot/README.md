# 🤖 Telegram Бот: Сборщик и Генератор Новостей (Полимеры/Пластик)

Этот бот автоматически собирает новости с указанных сайтов и Telegram-каналов, позволяет выбрать интересные темы, делает рерайт текста через ИИ и генерирует иллюстрации. Результат сохраняется в удобном формате (Word + JPG).

---

## 📋 Что нужно перед запуском

Вам понадобятся:
1. **Компьютер с Windows/Mac/Linux**, который будет всегда включен (или работать в фоновом режиме).
2. **Установленный Python** (версия 3.8 или выше).
3. **Аккаунт в Telegram** (для получения ключей).
4. **Доступ в интернет**.

---

## 🚀 Пошаговая инструкция по установке

### Шаг 1: Установка Python
Если у вас еще не установлен Python:
1. Скачайте установщик с официального сайта: [python.org](https://www.python.org/downloads/)
2. Запустите установщик.
3. ⚠️ **ВАЖНО:** При установке обязательно поставьте галочку **"Add Python to PATH"** (Добавить Python в переменную PATH).
4. Нажмите "Install Now".

### Шаг 2: Подготовка папки
1. Скопируйте папку с ботом (всю папку `news_bot`) в любое удобное место на компьютере (например, `C:\MyBot`).
2. Внутри папки создайте пустую папку с названием `output` (туда будут сохраняться новости).

### Шаг 3: Установка библиотек
1. Откройте командную строку (нажмите `Win + R`, введите `cmd` и нажмите Enter).
2. В черном окне введите команду для перехода в папку с ботом:
   ```bash
   cd C:\MyBot\news_bot
   ```
   *(Замените путь на ваш реальный путь к папке)*
3. Введите команду для установки всех необходимых компонентов:
   ```bash
   pip install -r requirements.txt
   ```
   *Дождитесь окончания установки (может занять 2-5 минут).*

### Шаг 4: Настройка ключей (Файл .env)
В папке с ботом найдите файл `.env.example`.
1. Скопируйте его и переименуйте копию в `.env` (точка в начале обязательна!).
   *Или просто создайте новый текстовый файл, назовите его `.env` и вставьте туда содержимое из примера.*
2. Откройте файл `.env` с помощью Блокнота.
3. Вам нужно заполнить значения после знака `=` для следующих строк:

#### Где взять ключи?

**1. TELEGRAM_BOT_TOKEN** (Токен вашего бота)
*   Откройте Telegram, найдите бота **@BotFather**.
*   Напишите ему `/newbot`.
*   Придумайте имя боту (например, `NewsMakerBot`) и юзернейм (должен заканчиваться на `bot`, например `SuperPlastNewsBot`).
*   BotFather пришлет длинный код — это и есть токен. Скопируйте его в файл `.env`.

**2. ADMIN_USER_ID** (Ваш личный ID)
*   В Telegram найдите бота **@userinfobot** (или аналогичный).
*   Нажмите `Start`. Он пришлет ваш числовой ID (например, `123456789`).
*   Вставьте этот номер в файл `.env`.

**3. TELETHON_API_ID и TELETHON_API_HASH** (Для чтения каналов)
*   Зайдите на сайт [my.telegram.org/apps](https://my.telegram.org/apps).
*   Введите номер телефона (как в Telegram), получите код подтверждения в приложении Telegram.
*   Заполните форму создания приложения (название любое, например `NewsParser`).
*   Скопируйте `api_id` (число) и `api_hash` (длинный код) в файл `.env`.

**4. TEXT_RU_API_KEY** (Для рерайта текста)
*   Зарегистрируйтесь на [text.ru/api](https://text.ru/api).
*   В личном кабинете найдите раздел API и скопируйте ключ.
*   *Примечание: Сервис платный, но дешевый (~0.4 руб за 1000 символов). Нужно пополнить баланс на сайте.*

**5. KANDINSKY_API_KEY и KANDINSKY_SECRET_KEY** (Для картинок)
*   Зарегистрируйтесь на [fusionbrain.ai](https://fusionbrain.ai/).
*   В личном кабинете создайте ключи API.
*   Вставьте их в файл `.env`.
*   *Альтернатива: Если ключей нет, бот может пропустить генерацию картинок (потребуется небольшая правка кода, но пока лучше получить ключи).*

4. **Сохраните** файл `.env` и закройте его.

### Шаг 5: Первичный запуск и настройка источников
1. Снова откройте командную строку (`cmd`) в папке с ботом.
2. Запустите скрипт настройки источников (он добавит сайты и каналы из вашего ТЗ):
   ```bash
   python init_sources.py
   ```
   *Вы должны увидеть сообщение: "Источники успешно добавлены!".*

### Шаг 6: Запуск бота
Теперь запустите самого бота:
```bash
python main.py
```

Если все настроено верно, в консоли появится надпись вроде: `Bot is running...`.
**Не закрывайте это черное окно!** Пока оно открыто, бот работает.

## 📱 Как пользоваться ботом

1. Зайдите в Telegram и найдите своего бота (по юзернейму, который вы придумали в шаге 4.1).
2. Нажмите кнопку **Запустить** (`/start`).
3. Бот поприветствует вас.

### Основные команды:
*   **📅 Настроить расписание**: Выберите день недели и время, когда бот должен сам собирать новости.
*   **🔍 Собрать новости сейчас**: Принудительный запуск сбора новостей прямо сейчас.
*   **➕ Добавить источник**: Возможность добавить новый сайт или канал.
*   **❌ Удалить источник**: Удалить ненужный источник.

### Сценарий работы:
1. Бот собирает новости (по расписанию или по кнопке).
2. Присылает вам список заголовков.
3. Вы выбираете галочками ✅ те новости, которые интересны.
4. Бот отправляет выбранные тексты на рерайт и генерирует картинки.
5. Готовые файлы сохраняются в папку `output` на компьютере в виде:
   `output/2023-10-25/Заголовок_новости/article.docx` + `image.jpg`.

## ❓ Частые проблемы

**Ошибка "ModuleNotFoundError"**
*   Решение: Вы забыли выполнить Шаг 3 (`pip install -r requirements.txt`) или установили библиотеки для другой версии Python.

**Бот не отвечает в Telegram**
*   Проверьте, не закрыли ли вы черное окно консоли.
*   Проверьте правильность `TELEGRAM_BOT_TOKEN` в файле `.env`.

**Ошибка при сборе новостей с сайта**
*   Некоторые сайты могут блокировать частые запросы. Попробуйте запустить позже.
*   Убедитесь, что у компьютера есть доступ в интернет.

**Мало денег на балансе TEXT.ru**
*   Бот напишет об ошибке рерайта. Пополните баланс на сайте text.ru и попробуйте новость снова.
