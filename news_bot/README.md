# Telegram News Bot - Бот для сбора и обработки новостей

## Обзор (Overview)

Бот для автоматического сбора новостей из Telegram каналов и веб-сайтов, их обработки через ИИ (рерайт текста + генерация изображений), и сохранения в организованной структуре папок.

**Основные возможности:**
- ✅ Сбор новостей из Telegram каналов и сайтов
- ✅ Автоматический запуск по расписанию (день недели + время)
- ✅ Рерайт текстов через TEXT.ru API
- ✅ Генерация изображений через Kandinsky API
- ✅ Сохранение в формате: `/дата/заголовок/article.docx + image.jpg`
- ✅ Интерактивный выбор интересных новостей
- ✅ Управление источниками (добавление/удаление)
- ✅ Предварительно настроенные источники из ТЗ

## Быстрый старт

### 1. Установите зависимости:
```bash
cd news_bot
pip install -r requirements.txt
```

### 2. Настройте переменные окружения:
```bash
cp .env.example .env
```

Откройте `.env` и заполните:
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
ADMIN_USER_ID=ваш_user_id
TELETHON_API_ID=api_id_для_telegram
TELETHON_API_HASH=api_hash_для_telegram
TEXT_RU_API_KEY=ключ_TEXT_ru
KANDINSKY_API_KEY=ключ_Kandinsky
KANDINSKY_SECRET_KEY=секретный_ключ_Kandinsky
```

### 4. Получите необходимые ключи:

#### Telegram Bot Token:
1. Откройте @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям

#### Telegram API (для парсинга каналов):
1. Перейдите на https://my.telegram.org
2. Войдите по номеру телефона
3. Создайте приложение и получите API ID и Hash

#### TEXT.ru API:
1. Зарегистрируйтесь на https://text.ru/api
2. Получите API ключ в личном кабинете
3. **Цена:** ~0.3-0.5 руб за 1000 символов

#### Kandinsky API (FusionBrain):
1. Зарегистрируйтесь на https://fusionbrain.ai
2. Получите API ключи в настройках
3. **Цена:** бесплатно ~10-20 изображений/день, далее ~$0.02-0.05 за изображение

### 5. Запустите бота:
```bash
python main.py
```

## Использование

### Команды бота:

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/add_source` | Добавить источник (Telegram канал или сайт) |
| `/list_sources` | Показать все источники с ID |
| `/remove_source <ID>` | Удалить источник по ID |
| `/schedule` | Настроить расписание автозапуска |
| `/parse_now` | Запустить сбор новостей вручную |
| `/settings` | Настройки и статистика |
| `/help` | Справка |

### Рабочий процесс:

1. **Источники уже добавлены** через `init_sources.py` (можно добавить свои через `/add_source`)
2. **Настройте расписание** через `/schedule` (например, Пн-Пт в 9:00)
3. **Запустите сбор** через `/parse_now` или дождитесь автозапуска
4. **Выберите интересные новости** отправив номера (например: `1, 3, 5` или `все`)
5. **Получите готовые файлы** с рерайтом и изображениями

## Альтернативные AI сервисы

### Для рерайта текста:
- **TEXT.ru** - рекомендуется для русского языка
- **OpenAI GPT-4** - выше качество, дороже (~$0.03/1K токенов)
- **YandexGPT** - хорошая альтернатива для русского

### Для генерации изображений:
- **Kandinsky 3.0** - рекомендуется (бесплатный лимит)
- **Stable Diffusion XL** (Replicate) - ~$0.002-0.007/изобр
- **DALL-E 3** (OpenAI) - ~$0.04/изобр

## Решение проблем

### Бот не запускается:
1. Проверьте, что все переменные в `.env` заполнены
2. Убедитесь, что токен бота правильный
3. Проверьте логи на ошибки

### Не работает парсинг Telegram:
1. Убедитесь, что API ID и Hash правильные
2. Бот должен быть администратором в канале ИЛИ используйте публичные каналы
3. Проверьте формат username (@channelname)

### Ошибки API TEXT.ru/Kandinsky:
1. Проверьте баланс/лимиты аккаунта
2. Убедитесь, что API ключи действительны
3. Попробуйте позже при превышении лимитов

### Проблемы с парсингом сайтов:
Некоторые сайты могут блокировать автоматический доступ. В этом случае:
1. Проверьте User-Agent в настройках парсера
2. Некоторые сайты требуют JavaScript для отображения контента
3. Рассмотрите использование API вместо парсинга
